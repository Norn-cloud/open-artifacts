## Design Specificity Verdict

为本产品而作，修复轮保持。三态在场指示、批处理工作流、split-brain frame 约束、内联 arm/revert 确认词汇均产品专属。detector：12 条全为其他表面（comments 抽屉/handoff/unlock/status 页），live chrome 零发现。

## Priority Issues

- P1 队列编辑无法取消 — 离线 Apply 后事件持久化于 DO 队列（实测 5 个不可取消事件），Discard 只清 stash；"it will queue" 是 UI 无法兑现的承诺。
- P2 陈旧 pill + 撒谎的 retry toast — commit 后标签停在 "Confirm apply?"；后续点击 409 却提示 "still here, try again"（实际已入队）。
- P2 Exit/Escape 静默丢弃批次 — reset() 清 items[] 无确认；批次不像 stash 持久化。
- P2 移动端无触摸选取路径 — picker 的 onClick 依赖 mousemove 设置 hover，静态 tap 无 mousemove；无 safe-area inset。
- P3 header CLS（28→104px）与 off-ramp 尺寸（dock 14px/bar 12px 圆角等）。
